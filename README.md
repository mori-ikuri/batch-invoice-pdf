# 請求書一括PDF作成ツール(Excel VBA)

「請求一覧」と「明細」のシートから、請求書を1件ずつPDFにする Excel のツールです。
仕事の進め方を見ていただくための見本で、会社名・顧客名・住所・番号はすべて架空です。

見本:[できた請求書のPDF](docs/見本/INV-1009_サンプル精機株式会社.pdf) / [エラー一覧の例(PDF)](docs/見本/エラー一覧の例.pdf)

## できること

- 請求一覧と明細のデータを、請求書のひな形に1件ずつ流し込み、1件ずつPDFに保存します。
- PDFのファイル名は「設定」シートのルールで決めます(例:`{請求番号}_{顧客名}.pdf`)。
- 作る前に全件をチェックし、**エラーが1件でもあれば1件も作らず**、「エラー一覧」シートに場所と直し方を出して止まります。
- 実行のたびに「実行履歴」シートへ、日時・作成件数・保存先を残します。
- 請求書は税率ごと(10%・8%)に小計と消費税を出します。8%の品目には「※」がつきます。

## 作り方で大事にしたこと

### 1. 作った人がいなくなっても回る

- **設定はシートに出す**:保存先、ファイル名のルール、同名ファイルがあるときの扱い、自社情報、登録番号、消費税の端数処理は「設定」シートにあります。コードを開かずに変えられます。
- **止まったら理由が見える**:入力の誤りは「エラー一覧」に、シート・行・請求番号・項目・直し方を出します。想定外のエラーでも、どの段階・どの請求番号で止まったかを画面と「実行履歴」に出します。
- **見た目はシートで直せる**:流し込み先はひな形シートの「名前の定義」で決めているので、レイアウトを変えてもコードは直しません。
- **手順書と引き継ぎメモ**:使う人向けの[手順書](docs/手順書.md)と、直す人向けの[引き継ぎメモ](docs/引き継ぎメモ.md#第1部-ブックだけで直す人へ)があります。引き継ぎメモは、ブックだけを受け取って直す人が読めば足りるように書いています。
- **確かめ方も残す**:動きを確かめるテスト(`tests\run-tests.ps1`)があり、直したあとに同じ確認をくり返せます。

### 2. データを外に出さない

- ネット通信・外部サービス・アドインを使いません。Excel と Windows に最初から入っている機能だけで動きます。
- PDFは、このPCの指定したフォルダにだけ保存します。
- PDFにはブックの作成者名などの情報を入れません。配るブックからも作成者名を消しています。

## シート

| シート | 中身 |
|---|---|
| 使い方 | ボタン(入力をチェック/PDFを作成/1件だけひな形に表示)と短い説明 |
| 設定 | 保存先、ファイル名ルール、同名ファイルの扱い、自社情報、登録番号、端数処理 など |
| 請求一覧 | 請求番号・請求日・顧客名・敬称・支払期限(1行が請求1件) |
| 明細 | 請求番号・品名・数量・単価・税率(請求番号で請求一覧と結びつく) |
| 請求書ひな形 | PDFになる請求書。税率ごとの小計と消費税は式で計算 |
| エラー一覧 | 入力チェックで見つけたエラー(シート・行・請求番号・項目・内容) |
| 実行履歴 | 実行の日時・操作・結果・作成件数・保存先・内容 |

## 動作環境

- Windows 10 / 11(日本語版)
- デスクトップ版の Excel(Microsoft 365、Excel 2016 以降を想定)。Web版・Mac版の Excel では動きません。
- 動作を確かめた環境:Windows 11 Pro、Microsoft 365 の Excel(バージョン 16.0.20527、64ビット)

## 使い方(短く)

1. `請求書一括PDF作成.xlsm` を開き、[コンテンツの有効化] でマクロを有効にします。
   インターネットから受け取ったブック(GitHub からダウンロードしたものなど)はマクロがブロックされ、[コンテンツの有効化] が出ません。信頼できるファイルか確かめてから、ファイルを右クリック → [プロパティ] で [許可する] にチェックを入れ、開き直してください(くわしくは[手順書の 2.](docs/手順書.md#2-ブックを開く))。
2. 「設定」シートで保存先フォルダと自社情報を確かめます(最初は、ブックと同じ場所の「出力」フォルダ)。
3. 「請求一覧」と「明細」にデータを入れます。
4. 「使い方」シートの [入力をチェック] → [PDFを作成] の順に押します。

## 開発する人へ

VBA のソースは `src/` が正本です。`.xlsm` はソースとデータから組み立てます。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tests\run-tests.ps1
```

組み立てには Excel の「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」は使いません(設定を変えずに組み立てられます)。仕組みと直し方は[引き継ぎメモの第2部](docs/引き継ぎメモ.md#第2部-このリポジトリで開発する人へ)にあります。
