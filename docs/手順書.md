# 手順書(使う人向け)

請求書一括PDF作成ツールの使い方です。マクロのことを知らなくても使えるように書いています。
直す人向けのことは [引き継ぎメモ](引き継ぎメモ.md#第1部-ブックだけで直す人へ) にあります。

## 1. はじめに

- 使うもの:Windows のPCと、デスクトップ版の Excel(Microsoft 365 など)。
- インターネットにつながっていなくても使えます。データやPDFを外へ送ることはありません。

## 2. ブックを開く

1. `請求書一括PDF作成.xlsm` を開きます。
2. 画面の上に「セキュリティの警告 マクロが無効にされました。」と出たら、[コンテンツの有効化] を押します。
3. 「このファイルのソースが信頼できないため、Microsoft によりマクロの実行がブロックされました。」と出たとき
   - インターネットやメールから受け取ったファイルに出ます。**信頼できる相手から受け取ったファイルかを確かめてから**、次のようにします。
   - Excel を閉じ、ファイルを右クリック → [プロパティ] → [全般] の下の「セキュリティ」で [許可する] にチェック → [OK]。もう一度開きます。
4. 会社のきまりでマクロが使えないPCもあります。そのときは、PCを管理している人に相談してください。

## 3. 毎回の流れ

1. 「請求一覧」と「明細」に、今回の請求のデータを入れます(入れ方は 4.)。
2. 「使い方」シートの [入力をチェック] を押します。
   - 保存先フォルダがまだないときは、最初に「このフォルダを作りますか?」と聞かれます。表示された場所でよければ [はい] を押します(5. の「保存先フォルダがないとき」)。
   - 「エラーはありません。請求 ○ 件のPDFを作成できます。」と出たら次へ。
   - 「入力にエラーが ○ 件あります。」と出たら、開いた「エラー一覧」シートを見て直し、もう一度 [入力をチェック] を押します(7. を見てください)。
3. [PDFを作成] を押します。
   - もう一度チェックが行われ、エラーがなければ「○ 件の請求書PDFを作成します。保存先:… よろしいですか?」と出ます。[OK] で作り始めます。
   - エラーが1件でもあれば、**1件も作らずに**止まります。
4. 「○ 件の請求書PDFを作成しました。」と出て、「保存先のフォルダを開きますか?」と聞かれます。[はい] でフォルダが開きます。
5. 「実行履歴」シートに、日時・作成件数・保存先が1行増えています。

見た目を先に確かめたいときは、[1件だけひな形に表示] を押して請求番号を入れると、その請求が「請求書ひな形」シートに表示されます(PDFは作りません)。
請求番号を入れる欄には、最初は「請求一覧」の先頭の請求番号が入っています。

## 4. データの入れ方

### 請求一覧(1行が請求1件)

| 見出し | 入れるもの | 決まり |
|---|---|---|
| 請求番号 | 例:INV-1001 | 必ず入れる。1件ごとに別の番号にする |
| 請求日 | 例:2026/10/31 | 必ず入れる。日付で入れる |
| 顧客名 | 例:株式会社ひな形システムズ | 必ず入れる。ファイル名にも使うので `\ / : * ? " < > |` は入れない |
| 敬称 | 例:御中、様 | 必ず入れる(御中・様は一覧から選べます。殿 などほかの敬称も入れられます) |
| 支払期限 | 例:2026/11/30 | 必ず入れる。請求日より前にはしない |

### 明細(1行が品目1つ)

| 見出し | 入れるもの | 決まり |
|---|---|---|
| 請求番号 | 例:INV-1001 | 「請求一覧」にある番号。これで請求と結びつきます |
| 日付 | 例:2026/10/05 | 必ず入れる。日付で入れる(取引の日。請求書には 10/5 の形で、入れた順のまま出ます) |
| 品名 | 例:コピー用紙 A4 500枚 | 必ず入れる |
| 数量 | 例:5 | 0より大きい数 |
| 単価 | 例:600 | 数。値引きは負の数(例:-2000) |
| 税率 | 10% か 8% | この2つだけ。「10」ではなく「10%」と入れます。8%の品目は請求書で「8%※」と出ます |

- 1件の請求に入れられる明細は **12行まで** です(請求書ひな形の行数)。超えるときは請求を分けてください。
- 表のすぐ下の行に入れると、表が自動で広がります。
- 列の順番は入れ替えてもかまいません。**見出しの文字は変えないでください**(マクロが見出しの文字で列を探します)。
- すべての列が空の行は、飛ばして読みます。フィルターで隠れている行も読みます。
- 顧客名・品名など(請求番号以外)は、式(VLOOKUP など)で出してもかまいません。式の結果がエラー値(#N/A など)になっている欄があると、作る前に止まります。
- 請求番号の列は、001 のような番号の 0 が消えないよう、表示形式を「文字列」にしています。この列に式を入れると、式のまま文字として入ります。

## 5. 設定の変え方

「設定」シートの **B列(値)** を書き換えます。**A列の項目名は変えないでください**(マクロが項目名で探します)。

| 項目 | 最初の値 | 説明 |
|---|---|---|
| ひな形シート名 | 請求書ひな形 | PDFにするシート。ひな形を作り替えるときは、シートをコピーして名前をここに書きます |
| 保存先フォルダ | 出力 | PDFを保存するフォルダ。「C:\請求書PDF」のようなフルパスか、ブックのある場所からの相対パス。フォルダがないときは、作るかを聞きます(表の下) |
| ファイル名ルール | {請求番号}_{顧客名}.pdf | 使える差し込み:{請求番号} {顧客名} {請求日}(20261031 の形)。最後は .pdf |
| 同名ファイルがあるとき | 止める | 「止める」:保存先に同じ名前のファイルが1つでもあれば、1件も作らずエラー一覧へ。「上書き」:置き換える |
| 実行後にブックを保存 | する | 「する」:実行履歴を残すため、実行のあとにブックを上書き保存します |
| 自社名・郵便番号・住所・電話番号 | (見本の架空の値) | 請求書の右上に出ます |
| 登録番号 | T0000000000000 | 適格請求書発行事業者の登録番号。T と数字13桁 |
| 振込先 | (見本の架空の値) | 請求書の「お振込先」に出ます |
| 消費税の端数処理 | 切り捨て | 「切り捨て」「四捨五入」「切り上げ」。税率ごとの合計に1回だけ行います |

### 保存先フォルダがないとき

[入力をチェック] か [PDFを作成] を押すと、最初に「保存先フォルダがありません:(フルパス)。このフォルダを作りますか?」と聞かれます。

- [はい]:フォルダを作って、そのまま続けます。
- [いいえ]:作らずに、「エラー一覧」に出して止まります。もう一度ボタンを押すと、また聞かれます。

作るのは、いちばん下の1つのフォルダだけです。その1つ上のフォルダもないとき(例:保存先が「C:\請求書PDF\2026年10月」で、「C:\請求書PDF」もない)は、聞かずに「エラー一覧」に出して止まります。ドライブ名やフォルダ名を打ち間違えたまま、思わぬ場所にフォルダとPDFができないようにするためです。

フォルダを作れなかったとき(書き込みの権限がない など)は、理由が出たあと「エラー一覧」に出て止まります。保存先を、書き込めるフォルダに直してください。

## 6. ボタン(「使い方」シート)

| ボタン | すること |
|---|---|
| 入力をチェック | 設定・請求一覧・明細を全件チェックします。PDFは作りません |
| PDFを作成 | チェックのあと、確認してから1件ずつPDFを作ります |
| 1件だけひな形に表示 | 指定した請求を「請求書ひな形」シートに表示します。PDFは作りません |

## 7. 止まったときの見方

### 7.1 「入力にエラーが ○ 件あります。」と出たとき

「エラー一覧」シートが開きます。1行が1つのエラーで、上から順に直していけば大丈夫です。

| 列 | 意味 |
|---|---|
| シート・行 | どこを直すか(「設定」「請求一覧」「明細」など、何行目か) |
| 請求番号 | どの請求のことか |
| 項目 | どの欄か |
| 内容 | 何が問題で、どう直すか |

よく出るエラー:

| 内容(はじめの部分) | 直し方 |
|---|---|
| 入っていません(必須です)。 | その欄に入れる |
| 請求番号が ○ 行目と重なっています。 | どちらかの請求番号を変える |
| 明細が1行もありません。 | 「明細」にその請求番号の行を入れる |
| この請求番号は「請求一覧」にありません。 | 番号の書き間違いを直すか、請求一覧に入れる |
| 明細が ○ 行あり、ひな形の明細欄(12 行)に入りきりません。 | 請求を分ける |
| 10% か 8% にしてください | 税率を 10% か 8% にする |
| 日付として読めません | 2026/10/31 の形で入れ直す。数字(46326 など)が出ているときは、セルの表示形式を日付にする |
| 数字が文字として入っています | セルの表示形式が「文字列」になっていないかを確かめ、数値として入れ直す |
| セルがエラー値(#N/A など)になっています | その欄の式や、式が参照している元のデータを直す |
| 請求が1件もありません | 「請求一覧」の2行目から請求を入れる |
| ファイル名に使えない文字 | 顧客名などから `\ / : * ? " < > |` や改行を取る |
| 保存先フォルダがありません | もう一度ボタンを押し、「このフォルダを作りますか?」で [はい] を押す。または設定の保存先を直す |
| 保存先フォルダも、その1つ上のフォルダもありません | 設定の保存先の打ち間違い(ドライブ名・フォルダ名)を直す。正しいときは、エクスプローラーでフォルダを作ってからやり直す |
| 保存先とファイル名を合わせた長さが 255 文字を超えます | 保存先を短い場所(例:C:\請求書PDF)にするか、ファイル名ルールを短くする |
| 保存先に同じ名前のファイルがあります | 前に作ったPDFを別の場所へ移すか、設定の「同名ファイルがあるとき」を「上書き」にする |
| ひな形シートが非表示になっています | シート見出しを右クリック → [再表示] で「請求書ひな形」を表示する |

直したら、もう一度 [入力をチェック] を押します。エラーがなくなると、エラー一覧の2行目に「エラーはありません」と出ます。

### 7.2 「想定外のエラーで止まりました。」と出たとき

入力チェックでは見つからない理由で止まったときです。画面と「実行履歴」シートに、次のことが出ます。

- 段階(設定の読み込み/データの読み込み/入力チェック/PDF作成)
- 請求番号(PDFを作っている途中で止まったとき。その請求は「請求書ひな形」シートに表示したままにしています)
- 内容とエラー番号
- それまでに作成したPDFの件数

よくある原因:

- **PDFをビューアーで開いたまま「上書き」した**:PDFを閉じてから、もう一度 [PDFを作成] を押します。
- **保存先に書き込めない**(権限がない、ネットワークのフォルダにつながっていない など):保存先を変えるか、管理している人に相談します。

途中まで作ったPDFは保存先に残ります。「同名ファイルがあるとき」が「止める」のままやり直すと、作ったぶんが「同じ名前のファイルがあります」になります。そのときは、作ったPDFを別の場所へ移すか、「上書き」にしてからやり直してください。

自分で直せないときは、画面のメッセージと「実行履歴」の行を、直す人に伝えてください。

### 7.3 「実行履歴」の見方

| 列 | 意味 |
|---|---|
| 実行日時 | ボタンを押した日時 |
| 操作 | 入力チェック/PDF作成 |
| 結果 | 完了/エラーあり/取りやめ(確認で [キャンセル])/中断(想定外のエラー) |
| 作成件数 | 作ったPDFの数 |
| 保存先 | PDFを保存したフォルダ |
| 内容 | エラーの件数や、止まった段階・請求番号 |

## 8. よくある質問

- **保存先のフォルダを、途中のフォルダまでまとめて作らないのはなぜ?**
  打ち間違いのまま、思わぬ場所にPDFができるのを防ぐためです。フォルダを作る前には場所を見せて聞き、作るのもいちばん下の1つのフォルダだけにしています。1つ上のフォルダもないときは打ち間違いを疑って、聞かずに止めます。正しい場所なら、エクスプローラーでフォルダを作ってからやり直してください。
- **OneDrive の上で開くと「相対パスを使えません」と出る**
  OneDrive の上ではブックの場所がインターネットのアドレスになるため、相対パスを決められません。保存先を「C:\請求書PDF」のようなフルパスにしてください。
- **読み取り専用で開いたら、実行履歴が残らなかった**
  読み取り専用のときは上書き保存できないため、メッセージに「上書き保存はしていません」と出ます。残したいときは名前を付けて保存してください。
- **請求書の見た目を変えたい・ロゴを入れたい**
  「請求書ひな形」シートを直します。ロゴは画像を印刷範囲の中に貼ります。差し込み先のセル(名前の定義)は消さないでください。くわしくは [引き継ぎメモの第1部](引き継ぎメモ.md#第1部-ブックだけで直す人へ) を見てください。
- **インボイス制度(適格請求書)に合っている?**
  適格請求書の記載事項6つ(発行者の名前と登録番号、取引年月日、取引の内容と軽減税率(8%)の品目の印、税率ごとの合計と税率、税率ごとの消費税額、宛先)を載せられる形にしています。取引年月日は、明細の「日付」を 10/5 の形で出しています。ほかに載せたいこと(対象の期間 など)があれば、使う会社のやり方に合わせてひな形に足してください。
